# alan

一具由数据构成、听起来像持续音（drone）的身体。这是 [monome norns](https://monome.org/docs/norns/) 的脚本：屏幕上是一个由点、线框和下落数字组成的 3D 人形。身体的每个部位都是一个声部，移动它，声音就会改变。

![alan](docs/sheet.png)

- **6 个永不停止的持续音声部**：躯干、头部、双臂和双腿
- **20 个关节**，用编码器逐个部位移动
- **自主运动**：身体会自己动，像一道波穿过各个关节
- **自由摄像机**：缩放、环绕和高度；可以直接穿过人形
- **呼吸与心跳**：胸口起伏，用力时心跳加快
- **解体**：身体和声音碎裂成粒子和颗粒
- **8 个姿势位**（7 个出厂姿势），可保存和调用
- 6 种音阶和可调主音，让一切保持和谐

## 需求

- norns（shield、标准版或 fates 均可）
- 不需要 MIDI 键盘或控制器：用编码器和按键演奏

## 安装

在 maiden 中：

```
;install https://github.com/buenosairesfront/alan
```

然后**重启 norns**（SYSTEM > RESTART）以编译新引擎 `Turing`，再从 SELECT 加载 **alan**。

## 开场

![开场](docs/1_title.png)

打开脚本时先出现 U-MA 开场，然后是 Alan 头部的特写和他的名字。摄像机逐渐拉远，直到看到整个身体。按任意键或转动任意编码器都可以跳过。

## 操作

### 移动身体

![选择部位](docs/3_select.png)

| 操作 | 作用 |
|---|---|
| E1 | 选择身体部位（左上角的小图会标出所选部位） |
| E2 / E3 | 移动所选部位（每个部位有两种动作） |
| 按住 K3 | 解体：身体散成粒子；松开后恢复 |
| 按住 K2 + E2 | 自主运动的速度 |
| 按住 K2 + E3 | 自主运动的幅度 |

部位顺序：头（转动／点头）、左肩、左肘、左髋、左膝和左踝、右膝和右踝、右髋、右肘、右肩和腰（弯曲／扭转）。

开启自主运动时，你碰过的部位会在你手中停留几秒，然后重新加入那道波。

### 摄像机

![摄像机](docs/5_camera.png)

点按 **K2** 进入或退出摄像机模式（屏幕四角会出现标记）。

| 操作 | 作用 |
|---|---|
| E1 | 缩放：靠近时摄像机对准头部；继续转动会穿过人形，从另一侧观看 |
| E2 | 绕身体环绕 |
| E3 | 高度（可以转一整圈） |

8 秒内没有任何操作时，摄像机会自动环绕（可在 PARAMS 中关闭）。

### 姿势与调音（按住 K1）

![一个姿势](docs/4_pose.png)

| 操作 | 作用 |
|---|---|
| K1 + E1 | 选择姿势（1 到 8）：转动时身体会依次经过每个姿势 |
| K1 + K2 | 把当前姿势存到该位置 |
| K1 + K3 | 载入该位置的姿势 |
| K1 + E2 | 呼吸 |
| K1 + E3 | 主音 |

保存的姿势存放在 `data/alan/poses.tab`，会取代该位置的出厂姿势。

## 声音如何产生

![运动中的身体](docs/2_body.png)

每个身体部位驱动一个声部。音符总是落在所选音阶上。

| 声部 | 声音 | 什么会改变它 |
|---|---|---|
| 躯干 | 低沉的次低音、心跳和气息 | 弯腰让声音变暗；扭转打开锯齿波合唱 |
| 头部 | 唱元音的合唱 | 抬头让音高升高；转头改变元音（a e i o u） |
| 手臂 | 共鸣的肌腱（噪声经共鸣器摩擦） | 手的高度决定音高，伸展距离打开滤波器，弯曲手肘让音色变得不谐和 |
| 腿部 | 低沉的骨头与木头声 | 脚的高度决定音高，张开髋部打开滤波器，弯曲膝盖会发出噼啪声 |

- 部位离静止位置越远，它的声部越响。
- 快速移动会让声音更响更亮，并在屏幕上抛出粒子。
- 声像和混响来自摄像机：屏幕左边的东西从左边发声，远处的东西听起来更远。
- 心跳会随着姿势的用力程度和运动而加快。

## 参数

在 PARAMS > alan 中：

| 参数 | 作用 |
|---|---|
| tonica | 主音，从 E1 到 E3 |
| escala | 音阶：多利亚、爱奥利亚、弗里几亚、利底亚、五声或五度 |
| respiracion | 身体（和声音）呼吸的幅度 |
| movimiento solo | 自主运动的幅度 |
| movimiento velocidad | 从每 50 秒一个周期到每 2.4 秒一个 |
| desintegracion base | 让身体始终保持轻微解体 |
| auto orbita | 8 秒无操作后摄像机自动旋转 |
| espacio (reverb) | 混响大小 |
| volumen | 总音量 |
| cuerpo | 全部 20 个关节，逐一调节（方便做 MIDI 映射） |

设备上的参数名称为西班牙语。退出脚本时会自动保存设置。
